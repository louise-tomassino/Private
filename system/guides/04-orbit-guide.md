# Orbit Guide

Your tasks and documents, accessible from any device.

---

## What is Orbit?

Orbit is a web app that shows your tasks and documents in a visual interface. Think of it as a companion to Claude Code — Claude is where you do the thinking, Orbit is where you glance at what's on your plate.

**What you can do in Orbit:**
- Check your tasks on your phone
- See everything on a kanban board (drag tasks between columns)
- Create quick tasks without opening the terminal
- Browse and edit your documents
- Share access with family members or colleagues

---

## Orbit vs Claude Code

| I want to... | Use |
|--------------|-----|
| Check what's on my plate | Orbit |
| Create a quick task | Orbit |
| Drag tasks around a kanban board | Orbit |
| Check tasks on my phone | Orbit |
| Plan my week or prioritize | Claude Code |
| Process my inbox | Claude Code |
| Build something | Claude Code |
| Anything that needs judgment | Claude Code |

**Rule of thumb:** If you're just looking or doing something simple, use Orbit. If you need thinking or complex operations, talk to Claude.

## Getting Started

Ask Claude to help you set up Orbit: "Help me set up Orbit." Claude will walk you through the installation and configuration. See `system/guides/04b-orbit-reference.md` for the full technical setup details.

Once it's running, you'll see a task board. That's it — you're ready to go.

## Categories

Orbit organizes tasks into **categories** — the same ones you use in Alfred OS:

| Category | What goes here |
|----------|---------------|
| **Work** | Professional tasks and projects |
| **Personal** | Your own tasks — health, hobbies, learning |
| **Family** | Shared household and family tasks |

**If you use one repo:** All your tasks show up together, organized by the labels you already have.

**If you use separate repos:** Each repo maps to its category automatically.

You configure which repos belong to which category in Settings.

## Using Orbit Day-to-Day

### Viewing Tasks

Your tasks appear as cards on a kanban board. By default, they're grouped by **priority**:

| Column | Meaning |
|--------|---------|
| **Triage** | New tasks that need prioritizing |
| **Today** | Must do today |
| **This Week** | Do this week |
| **This Month** | Do this month |
| **Later** | No rush |

Drag tasks between columns to change their priority.

### Creating Tasks

Click the **+** button. Give it a title, pick a category, and you're done. The task shows up in Claude Code too — it's the same task list.

### Task Details

Click any task to see the full details. From there you can:
- Edit the title and description
- Set priority, status, and due date
- Add comments
- Check off subtasks
- Close it when you're done

### Searching and Filtering

Use the search bar to find tasks by name. Filter by category, label, or assignee to narrow things down.

---

## Tips

1. **Add Orbit to your phone's home screen** — It's designed for mobile. Long-press the share button in your browser and tap "Add to Home Screen."

2. **Use the priority columns** — Drag tasks into Today / This Week / This Month. It keeps you focused.

3. **Don't overthink it** — Orbit is for quick glances and simple actions. For anything complex, talk to Claude.
