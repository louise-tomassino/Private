# Wispr Flow Guide

Voice dictation that makes talking to Claude effortless.

---

## Why Voice Matters

LLMs need context. The more context you give, the better the output.

**The problem:** Typing is slow. When typing is slow, you get lazy:
- You leave out details
- You simplify
- You don't explain the full picture

**The solution:** Voice removes the friction between your brain and the prompt.

When you talk, you naturally ramble. You add:
- "oh, and also..."
- "the reason I want this is..."
- "and by the way..."

All that context makes Claude actually understand what you need.

---

## The Difference

**Typing:**
```
Make me a dashboard
```

**Talking:**
```
Make me a dashboard, I want to see my tasks for today,
maybe the weather, I'm in Stockholm so use that location,
and actually I'd love to see my calendar too, and keep it
simple, I don't want anything fancy, just clean and readable
```

Same intent. Wildly different results.

## What is Wispr Flow?

A voice dictation app that transcribes your speech in real-time.

- Works anywhere you can type
- Punctuates automatically
- Handles filler words
- Very accurate

## Setup

1. **Download:** https://wispr.flow
   - Available for Mac, Windows, iOS

2. **Install and configure:**
   - Set your preferred activation (keyboard shortcut or button)
   - Configure language settings

3. **Use it:**
   - Activate Wispr Flow
   - Talk
   - Text appears where your cursor is

## Tips for Effective Dictation

### 1. Just talk naturally

Don't try to be formal or structured. Ramble. Claude can parse it.

### 2. Include the "why"

"Make a dashboard" vs "Make a dashboard because I want to see my tasks first thing in the morning without opening three different apps"

The second gives Claude context to make better decisions.

### 3. Think out loud

Uncertainty is fine:
```
I'm not sure if I should do this as a separate page or
add it to the existing one, maybe you can suggest which
makes more sense given the structure we have
```

### 4. Correct as you go

If you misspeak, just correct yourself:
```
Add a task to the family category, actually no wait,
put it in private instead
```

Claude understands corrections.

## When to Use Voice vs Typing

**Use voice for:**
- Complex requests with lots of context
- Brainstorming and thinking out loud
- Long explanations
- When you're not sure what you want (let it flow)

**Use typing for:**
- Short, specific commands
- Code snippets or exact text
- When you need precision
- In meetings or public places

---

## Common Objections

**"I feel weird talking to my computer"**
You'll get over it in 2 days. The speed gain is worth the awkwardness.

**"It makes mistakes"**
Occasionally, but Claude understands context. A typo rarely matters.

**"I type faster than I talk"**
You might type faster, but you think and talk faster. Voice captures more of your thinking.
