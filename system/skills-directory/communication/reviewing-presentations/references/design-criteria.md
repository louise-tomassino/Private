# Design Criteria

Concrete, measurable checkpoints for evaluating slide design. Use these during the review process when assessing visual and design aspects.

---

## Typography

### Font Size Minimums (Live Presentation)

| Element | Minimum | Ideal Range |
|---------|---------|-------------|
| Titles / Headlines | 32pt | 36-44pt |
| Subtitles | 28pt | 28-32pt |
| Body text | 24pt | 24-40pt |
| Captions / footnotes | 14pt | 14-20pt |

**The back-of-room test:** Design for readability from 30+ feet. If someone in the last row can't read it, increase the size or cut the text.

### Font Rules

- Maximum **2-3 font families** in the entire deck
- Line spacing: **1.2-1.5x** (never single-spaced)
- Body text: **left-aligned** (center-aligned paragraphs are harder to read)
- Bold and italic: used for **emphasis on specific words**, not applied to entire paragraphs
- No drop shadows, bevels, or 3D effects on text
- Text-background contrast ratio: **4.5:1 minimum** (WCAG standard for accessibility)

### The Kawasaki Test

Guy Kawasaki's rule: nothing smaller than 30pt. This forces discipline — if you can't fit it at 30pt, you have too much text.

### The 5/5/5 Rule

A secondary benchmark: no more than 5 words per line, 5 lines of text per slide, and no more than 5 text-heavy slides in a row.

## Visual Hierarchy

### The Core Question

Can you identify the single most important element on each slide within 3 seconds?

### Hierarchy Checklist

- [ ] **One dominant element** per slide (via size, color, or position)
- [ ] **Clear size ratio** between headings and body text (aim for 3:1)
- [ ] **White space** separates distinct ideas
- [ ] **Related items grouped** together (proximity principle)
- [ ] **Most important content** in the top-left quadrant (where 69% of viewing time concentrates)
- [ ] **One accent color** for emphasis, not a rainbow
- [ ] **No competing elements** — if everything is bold, nothing is bold

### The Squint Test

Squint at the slide until it blurs. You should still be able to identify:
1. The headline
2. The primary visual element

If everything blends into a uniform gray mass, the hierarchy has failed.

### The Glance Test (Nancy Duarte)

Can each slide be comprehended in **3 seconds or less**? Evaluate across:

1. **Message singularity** — Is there one idea?
2. **Audience relevance** — Does it speak to their needs?
3. **Visual clarity** — Are colors, fonts, images clear?
4. **Data meaning** — Do data slides show insight, not just numbers?
5. **Arrangement** — Do contrast, whitespace, and flow guide the eye?

### Eye Flow Patterns

Slides should work with how people naturally scan:

- **Z-Pattern** (image-heavy slides): Top-left → top-right → bottom-left → bottom-right. Place headlines top-left, key visuals center-right, call-to-action bottom-right.
- **F-Pattern** (text-heavy slides): First full line → progressively shorter scans downward. Front-load important words at the start of each line.

## Cognitive Load

### The Science

Working memory holds approximately 7 chunks of information but can actively process only about 4 at a time. When a slide presents 15 separate pieces of information, retention collapses.

### Cognitive Load Checklist

- [ ] **One idea per slide** — If you need two sentences to describe what the slide is about, split it
- [ ] **Passes the 5-second rule** — Someone can identify the main point in 5 seconds
- [ ] **No dual-channel conflict** — Presenter isn't reading what's on screen (audiences can't read and listen simultaneously)
- [ ] **No complex diagram + dense text** on the same slide (research shows audiences fixate on text and ignore the diagram)
- [ ] **Every element is necessary** — No decorative clip art, irrelevant stock photos, or logos on every slide
- [ ] **Progressive disclosure** for complex content — Revealed step-by-step, not all at once
- [ ] **Maximum 6 elements** per slide (beyond this, cognitive load spikes ~500%)

### The Redundancy Trap

If the slide says it and the presenter says it, comprehension drops. The brain can't process two simultaneous language inputs (reading + listening).

**Slides should complement the speaker, not duplicate them.**

- Slide shows the key phrase or visual
- Presenter expands, explains, tells the story
- Together they create more than either alone

### The Non-Expert Test

Show the deck to someone unfamiliar with the topic. If they get lost, that's a design failure, not an audience failure.

## Slide Density Benchmarks

### Element Count Guide

| Elements on Slide | Assessment |
|-------------------|------------|
| 1-3 | Clean, focused — strong |
| 4-6 | Acceptable if well-organized |
| 7-9 | Getting crowded — consider splitting |
| 10+ | Overloaded — must simplify |

"Elements" includes: headline, bullet points (each one), images, chart, table, icons, logos, footnotes.

### Table Complexity

| Dimension | Guideline |
|-----------|-----------|
| Columns | Maximum 5 for live presentation |
| Rows | Maximum 6-7 for live presentation |
| Larger tables | Split across slides, or move to handout |
| Highlighting | Bold or color the row/column that matters — don't make the audience hunt |

### Bullet Points

- If a slide has more than 5 bullet points, it needs to be split
- If bullet points are full sentences, they should be shortened to phrases
- If every slide is bullets, the presentation is a document pretending to be a deck

## Color and Contrast

### Color Rules

- **2-4 colors maximum** across the deck (plus neutrals)
- **One accent color** for emphasis and calls to attention
- Colors should have **clear purpose** (not decoration)
- Test for **color blindness accessibility** — don't rely on red/green distinction alone

### Contrast

- Dark text on light background (preferred for well-lit rooms)
- Light text on dark background (works for dim rooms, screens)
- Never: light text on medium background, or dark text on dark background
- **4.5:1 contrast ratio minimum** between text and background

## Consistency

### What Must Be Consistent

- Font choices (same fonts throughout)
- Color palette (same colors throughout)
- Heading sizes (same hierarchy on every slide)
- Alignment grid (elements align to the same underlying structure)
- Spacing (consistent margins and padding)
- Style of visuals (all photos, or all illustrations — not a mix)

### The "Same Deck" Test

Could you shuffle any two slides next to each other and they'd look like they belong together? If some slides feel like they came from a different presentation, there's a consistency problem.

## Layout Principles

### The CRAP Principles (Robin Williams)

| Principle | What It Means | How to Check |
|-----------|---------------|--------------|
| **Contrast** | Different elements look noticeably different | Is there a clear visual distinction between headings, body, and secondary text? |
| **Repetition** | Visual elements repeat throughout | Are the same styles used consistently for the same types of content? |
| **Alignment** | Every element has a visual connection to something else | If you drew lines extending from each element's edges, would they connect to other elements? |
| **Proximity** | Related items are close together | Are things that belong together visually grouped? Are unrelated things separated? |

### Whitespace

Whitespace is not wasted space. It:
- Directs attention to what matters
- Reduces cognitive load
- Creates visual breathing room
- Signals confidence (cluttered slides suggest the presenter doesn't know what matters)

**Check:** Is there at least 20% empty space on each slide? Edge-to-edge content is a red flag.

## Quick-Pass Evaluation Checklist

Use this for a rapid scan of a near-final deck:

### Per-Slide Pass
- [ ] One dominant idea
- [ ] Headline is an assertion, not a label
- [ ] Text is 24pt+ for live presentation
- [ ] Maximum 6 elements
- [ ] One focal point (passes squint test)
- [ ] No text the presenter will read aloud verbatim
- [ ] Whitespace present

### Whole-Deck Pass
- [ ] Headlines read in sequence tell a story
- [ ] Problem established before solutions
- [ ] Identifiable climax moment
- [ ] Specific call to action at the end
- [ ] Consistent fonts, colors, alignment
- [ ] Engagement moment every 15-20 minutes
- [ ] Breather slides between dense sections
- [ ] All visuals serve the message (no decoration)
- [ ] No more than 5 text-heavy slides in a row
