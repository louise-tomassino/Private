# Evaluation Framework

Detailed frameworks for evaluating presentation structure, narrative, and content. Referenced during the review process when deeper analysis is needed.

---

## Narrative Structure Assessment

### The Sparkline Analysis (Nancy Duarte)

Great presentations oscillate between **"What Is"** (current reality) and **"What Could Be"** (the vision). Map the presentation on a timeline:

- **Bottom:** "What Is" — the status quo, problems, current pain
- **Top:** "What Could Be" — the future, the solution, the possibility

A strong presentation sails back and forth between these poles multiple times before reaching the **"New Bliss"** (the call to action).

**Evaluation questions:**
1. Does the opening establish a clear "what is" that the audience recognizes?
2. Does it paint a compelling "what could be" that the audience wants?
3. Does it alternate between these, creating tension and release?
4. Does it build to a clear call to action?
5. Is there at least one **S.T.A.R. moment** (Something They'll Always Remember)?

### S.T.A.R. Moment Types

| Type | Description | Example |
|------|-------------|---------|
| **Memorable dramatization** | A prop, demo, or physical demonstration | Steve Jobs pulling the MacBook Air from an envelope |
| **Repeatable sound bite** | A phrase designed to be quoted | "One more thing..." |
| **Evocative visual** | An image that sticks | A single powerful photograph instead of a data table |
| **Emotive story** | A human narrative that creates feeling | A customer story showing before and after |
| **Shocking statistic** | A number that reframes understanding | "Only 3% of people who buy ChatGPT Plus use it for more than basic Q&A" |

### The SCQA Framework

For business and educational presentations, check for this underlying structure:

- **S**ituation: What context does the audience already know?
- **C**omplication: What changed, went wrong, or creates tension?
- **Q**uestion: What must we figure out? (can be implicit)
- **A**nswer: What's the recommendation or path forward?

If any element is missing, the presentation will feel incomplete:
- Missing Situation → audience doesn't know why they should care
- Missing Complication → no tension, no urgency
- Missing Question → audience doesn't know what problem is being solved
- Missing Answer → presentation ends without direction

## Structural Tests

### The Headline Scan Test

List all slide titles in sequence. Read them aloud. They should form a logical argument:

**Weak** (topic labels):
> Introduction → Background → The Tools → Data → Results → Conclusion

**Strong** (assertions that tell a story):
> The AI gap isn't about competence → It's about technical setup → Claude Code bridges that gap → Here's what it connects to → This changes how you work → Let's build yours today

If the headlines don't tell a story, the structure needs work.

### The "So What?" Test

After each major section, ask: **"So what? Why does this matter to the audience?"**

If the presentation doesn't answer this — explicitly or implicitly — there's a narrative gap. Every section should connect to something the audience cares about.

### The First-and-Last Test

Remove all slides except the first and last. Is the transformation clear? Can you see the journey from where the audience starts to where they end up?

If the beginning and end feel disconnected, the presentation's arc is broken.

### The "Remove It" Test

For any slide or section you're unsure about, ask: **"If I removed this entirely, would the presentation suffer?"**

If the answer is no, it shouldn't be there. Every slide must earn its place.

## Content Assessment by Slide Type

### Opening Slides

**Purpose:** Create context, establish relevance, generate interest.

| Check | Pass | Fail |
|-------|------|------|
| Does it answer "Why should I care?" | Within first 3 slides | Audience has to wait 10+ slides to understand relevance |
| Does it set expectations? | Clear agenda or roadmap | Audience doesn't know where this is going |
| Does it establish credibility? | Brief, relevant, not boastful | Long bio, irrelevant credentials, or no credibility at all |

### Content/Teaching Slides

**Purpose:** Transfer knowledge, build understanding.

| Check | Pass | Fail |
|-------|------|------|
| One idea per slide? | Each slide makes one clear point | Slide covers 3 concepts with 8 bullet points |
| Assertion headline? | "58% drop off at checkout" | "Key Findings" |
| Evidence supports the assertion? | Visual, data, or example backs up the headline | Headline says one thing, body shows something else |
| Audience can process it? | Passes the 5-second test | Requires careful study to understand |

### Data Slides

**Purpose:** Use numbers to support the argument.

| Check | Pass | Fail |
|-------|------|------|
| Insight headline? | States the takeaway: "Sales grew 30% after launch" | Labels the topic: "Sales Data" |
| Right chart type? | Bar for comparison, line for trends, pie only for parts of a whole | Pie chart with 12 slices, 3D bar chart |
| Simplified? | Key data highlighted, clutter removed | Gridlines, borders, legends, footnotes all visible |
| Honest? | Axes start at zero (or labeled if not), no distortion | Truncated axis that exaggerates difference |

### Transition Slides

**Purpose:** Bridge between sections, give the audience a mental reset.

| Check | Pass | Fail |
|-------|------|------|
| Clear section shift? | Visual or verbal signal that we're moving on | New topic starts with no transition |
| Brief? | One slide, minimal text | Full paragraph explaining what's coming next |
| Energy reset? | Visual breather (image, quote, question) | Another dense text slide |

### Activity/Workshop Slides

**Purpose:** Prompt the audience to do something.

| Check | Pass | Fail |
|-------|------|------|
| Clear instructions? | Numbered steps: what, how long, expected output | Paragraph of text explaining the exercise |
| Self-sufficient? | Participant can follow without the facilitator speaking | Instructions only make sense with verbal context |
| Output defined? | "Write 3 bullet points" or "Discuss with your neighbor" | "Think about this" with no concrete action |
| Time specified? | "You have 5 minutes" | No time guidance |

### Closing Slides

**Purpose:** Land the message, drive action.

| Check | Pass | Fail |
|-------|------|------|
| Specific call to action? | "Start each day with /daily this week" | "Thank you!" or "Any questions?" |
| Emotional landing? | Returns to the opening tension and resolves it | Ends abruptly after the last content point |
| Memorable? | Leaves the audience with something to carry forward | Forgettable summary slide |

## Audience Centricity Assessment

The presenter is the guide. The audience is the hero. Check:

1. **Language level:** Does the vocabulary match the audience's expertise? (No unexplained jargon for beginners; no over-simplification for experts.)
2. **Assumed knowledge:** What does the presentation assume the audience already knows? Are those assumptions correct?
3. **Relevance framing:** Does each section connect to what the audience cares about, or what the presenter cares about?
4. **Engagement design:** How often is the audience asked to do something (think, discuss, write, respond)?

| Audience Type | What They Need | Common Mistake |
|---------------|----------------|----------------|
| **Beginners** | Context, reassurance, concrete examples | Too much jargon, moving too fast |
| **Experts** | Depth, nuance, new perspectives | Over-explaining basics they already know |
| **Executives** | Bottom line, strategic implications, decisions needed | Too much detail, not enough "so what?" |
| **Mixed** | Layered content (overview + optional depth) | Pitching to one segment while losing another |

## Engagement Pattern Assessment

Map when the audience is passive (listening) vs. active (doing). Look for:

- **Dead zones:** Stretches of 15+ minutes with no interaction
- **Front-loading:** All content in the first half, rushed activities at the end
- **False engagement:** "Any questions?" is not real engagement (nobody asks questions in the first half of a presentation)

**Effective engagement patterns:**

| Technique | When to Use | Duration |
|-----------|------------|----------|
| Reflection question on screen | After introducing a key concept | 30-60 seconds |
| Turn to your neighbor | After a provocative claim or data point | 2-3 minutes |
| Hands up / poll | To gauge the room's experience or opinion | 30 seconds |
| Individual exercise | After teaching a skill | 5-10 minutes |
| Group discussion | After exercises or at section transitions | 5-10 minutes |
| Live demonstration | When showing a tool or process | 3-5 minutes |
