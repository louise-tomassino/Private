# Skills Catalog

Optional skills you can add to Alfred OS. All skills in this catalog have been vetted for security, quality, and usability.

To install any skill, just say: **"Install [skill-name]"** — or say **"What skills are available?"** to browse.

---

## Core Skills

These ship with every Alfred OS installation in `.claude/skills/` and are always available. You don't need to install them.

| Skill | Description |
|-------|-------------|
| onboarding | First-time setup and ongoing learning progression |
| processing-inbox | Email triage, response drafting, and digests |
| creating-skills | Build custom skills for your own workflows |
| installing-skills | Browse and install optional skills from this catalog |
| whats-possible | Discover what Alfred can do with concrete examples |
| troubleshooting | Diagnose and fix common setup issues |
| reviewing-skills | Review downloaded or custom skills for security and quality |
| starting-new-things | Determine the right container for new initiatives |
| avoiding-duplicates | Prevent duplicate drafts and tasks during inbox processing |
